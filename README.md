# バス出発カウントダウン (Bus Departure Countdown)

## 概要
このアプリケーションは、特定のバス路線の出発時刻をリアルタイムで管理・表示するためのWebアプリケーションです。
ユーザーに対して「現在の時刻」と「各路線の次の出発時刻まであとどれくらいか（カウントダウン）」を直感的なUIで提供します。

バス停などの公共スペースや、乗客のスマートフォンで確認するための情報ツールとして最適化されています。

## 主な機能
- **リアルタイム時刻表示**: 画面上部に現在時刻を秒単位で常時表示します。
- **次発時刻の自動計算**: 定義された時刻表に基づき、現在の時刻から「次に来る出発時刻」を動的に算出します。
- **動的な時刻表レンダリング**:
    - 各ルートのすべての出発時刻をリスト表示します。
    - 次に出発する便を自動で検出し、視覚的に強調表示します。
- **翌日判定ロジック**:
    - 全ての時刻が過ぎている場合、翌日の最初の時刻を自動的に特定します。
    - 翌日の便か当日の便かによって、表示色（青/赤）やラベルを自動で切り替えます。
- **レスポンシブなデザイン**: モバイル端末でも見やすいカード形式を採用しています。

## 技術スタック
- **Frontend**:
    - HTML5
    - CSS3
    - JavaScript (Vanilla JS)
- **ライブラリ**: なし（外部ライブラリに依存しない純粋なフロントエンド実装）

## セットアップ・起動方法
このプロジェクトは静的なフロントエンド技術で構成されているため、特別なビルドプロセスや依存関係のインストールは不要です。

### 起動手順
1.  **リポジトリの取得**: プロジェクトフォルダを任意の場所に配置します。
2.  **ブラウザで開く**: `index.html` をお使いのブラウザで直接開きます。
    - 例: `file:///path/to/bus/index.html`
3.  **ローカルサーバー（推奨）**: 
    - VS Code を使用している場合は、**Live Server** 拡張機能を使用して `index.html` を起動すると、変更を即座に反映できるため便利です。
